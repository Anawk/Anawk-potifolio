# Portfólio | Ana Maria Costa Lima

Portfólio pessoal de Ana Maria, desenvolvedora de software e estudante de Engenharia de Software no Ibmec.

## Sobre

Site estático com apresentação, tecnologias, projetos, experiência profissional, formação e contato.

## Tecnologias

- HTML semântico
- CSS3 com variáveis nativas e tema claro/escuro
- JavaScript (alternância de tema com `localStorage`, acordeão e efeito de texto no título)
- Layout responsivo (mobile first)

## Como rodar

Abra o `index.html` no navegador, ou use qualquer servidor estático (por exemplo, a extensão Live Server do VS Code).

## Deploy

O workflow em `.github/workflows/deploy.yml` publica o site no GitHub Pages a cada push na branch `main`.
Para ativar: no repositório, vá em **Settings > Pages** e em **Source** escolha **GitHub Actions**.
